How these numbers are measured

Baseline. For each call, code-graf prices what an agent without the graph would realistically do: grep the question's terms and read the top 8 matching files in full (symbol reads are priced against reading the whole file). This is deliberately conservative: it is far less than "read the whole repo", the number Graphify's own benchmark compares against.

Tokens. estimate (chars / 4). Install code-graf[accurate] for exact cl100k counts; absolute numbers shift a little, ratios barely move.

Not counted. Savings are counted once per call. In a real session, tokens that stay in context are re-sent on every later turn, so the real saving compounds; this dashboard does not claim that. Shell-output savings (code-graf run) are exact: raw vs compressed.

Quality. A benchmark task counts as answered only if the expected symbol appears with its source code in the output.

code-graf is a companion layer on top of Graphify. Graph, communities and AST extraction are Graphify's; code-graf adds symbol-level retrieval, context packs, hooks, MCP, and this honest accounting.
