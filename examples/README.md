# Example output

`flask-demo/` is a real run of `graphsnip demo --bundle` on the public Flask repository (pallets/flask):
a Graphify graph of 2,325 nodes, the benchmark, and the dashboard with Graphify's interactive graph embedded.

Open `flask-demo/dashboard.html` in a browser. It is a static, self-contained folder (no server, works offline).
The numbers in it are from the benchmark, not from live agent usage; run `graphsnip init` on your own repo to get yours.
