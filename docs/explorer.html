4 · Who does what

Graphify parses your code (tree-sitter, no LLM, runs locally) into a knowledge graph: symbols, calls, inheritance, communities, an interactive graph.html. Its query returns a map of where things are, without the source.
graphsnip sits on top and returns the exact code of one symbol or a ranked, token-budgeted context pack, so the agent does not read whole files afterwards. It also suppresses repeats, adds hooks and slash commands for Claude Code, Copilot and Codex, and keeps an honest savings ledger.
Routing sends light questions to a cheaper model tier and hands hard ones to a stronger one. It saves dollars per token, not tokens, and is only counted when the running model matched the decision.
